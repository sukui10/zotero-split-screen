# Zotero 论文分屏

一个面向 Zotero 7–9 的论文对比工作台。它在 Zotero 主窗口中创建“论文对比”标签页，并把原生 PDF Reader 直接嵌入多个可切换窗格中。

## 当前功能

- 在 Zotero 主窗口内打开“论文对比”标签页，不再弹出多个独立 Reader 窗口。
- 左侧候选文献栏默认约 210px，可拖动调宽或折叠为窄边栏；支持搜索以及一键放入 A/B 窗格。
- 可直接读取 Zotero 顶部已经打开的 PDF 标签页，并随时刷新候选文献。
- 默认只显示 A/B 双栏；上下布局固定显示 2 个窗格，网格布局由用户主动开启并最多显示 4 个窗格。
- 窗格使用完整 Reader 模式，保留文字层、原生工具栏、搜索、批注、阅读器侧栏和 Reader 插件事件。
- 支持交换前两个窗格，以及聚焦单篇文献进行精读和标注。
- 高亮任意窗格即可将其设为同步主文献，并控制其他窗格同步页码。
- 提供所有窗格同时上一页/下一页的阅读控制。
- 右侧提供真实的 Zotero 原生富文本笔记，以及可交互填写的 A/B 结构化对比表。
- PDF 批注或文字可拖入结构化字段，并生成表格写回同一个 Zotero 笔记。
- 工作台会保存侧栏宽度、折叠状态、布局、窗格文献和最近阅读页。

## 安装

仓库已经可以直接构建为 XPI：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

随后在 Zotero 中选择：

1. “工具 → 附加组件”。
2. 点击右上角齿轮按钮。
3. 选择“Install Add-on From File…”（从文件安装插件）。
4. 选择 `dist` 目录中生成的 `.xpi` 文件并重启 Zotero（如有提示）。

## 使用

1. 在文献列表中选择带有 PDF 附件的文献。
2. 右键选择“在论文对比工作台中打开”，或使用“工具 → 论文对比 → 打开或添加所选文献”。
3. 在新出现的 Zotero 标签页中，点击一个中间窗格使其高亮；随后点击左侧任意文献即可将该窗格切换为对应论文。
4. 使用顶部工具栏切换布局、交换文献、聚焦标注、同步页码或设置“对齐当前页”。
5. 在右侧切换“Zotero 笔记”和“结构化对比”；结构化内容可以生成表格写回原生笔记。

## 同步行为

当前版本同步的是 PDF 页码，而不是像素级滚动位置。这样不会依赖 PDF.js 的滚动 DOM，跨 Zotero 版本更稳定，也适合对比章节结构相近的论文。不同论文的封面、目录页数差异较大时，可以暂停同步，分别定位到方法或实验章节后再恢复。

## 兼容性与限制

- 清单声明支持 Zotero 7.0–9.0.x。
- Zotero 9 的插件验证器要求提供更新地址；当前本地开发包使用一个保留的空更新地址，因此不会自动下载更新。后续发布时应替换为实际的 `updates.json` 地址。
- 目前只处理 PDF，不处理 EPUB、网页快照或补充材料压缩包。
- 每篇普通文献默认选取第一个 PDF 附件。
- 内嵌窗格复用了 Zotero 9 的内部 Reader 接口；主版本更新后如果 Zotero 调整该接口，插件可能需要同步适配。
- 部分只识别标准 `ReaderTab` 的第三方插件仍可能无法识别对比窗格；通过 Reader 事件挂载工具栏或批注流程的插件通常可以继续工作。
- 当前尚未实现章节语义自动对齐和像素级同步滚动。

## 项目结构

- `bootstrap.js`：Zotero 插件生命周期入口。
- `split-screen.js`：文献解析、Reader 窗口管理、布局和同步逻辑。
- `manifest.json`：Zotero 插件清单。
- `scripts/build.ps1`：静态检查并生成可安装的 XPI。
- `tests/core.test.js`：布局计算和 PDF 附件解析的无依赖测试。
- `docs/TESTING.md`：手动验收清单。

## 开发调试

修改代码后重新执行构建脚本并在 Zotero 中重新安装 XPI。遇到问题时，可在 Zotero 的“帮助 → 调试输出日志”中查看以 `Zotero Split Screen:` 开头的日志。
